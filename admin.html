Paramètres du dépôt GitHub

🛠️ Configuration initiale (propriétaire du site uniquement)

Aucun identifiant n'est encore configuré. Cette étape se fait une seule fois, par la personne qui gère le dépôt GitHub. Le token n'est jamais envoyé nulle part : tout se calcule dans votre navigateur.

  1. Créez un fine-grained personal access token GitHub, limité à ce dépôt, permission Contents: Read and write uniquement.
  2. Collez-le ci-dessous avec le mot de passe éditeur que vous voulez donner à vos collaborateurs (ex : APF2026!).
  3. Cliquez sur « Générer », copiez le bloc obtenu, et collez-le dans assets/config.js à la place de encryptedToken: null, puis commitez/pushez ce fichier.

🔒 Connexion éditeur

Entrez le mot de passe qui vous a été communiqué pour pouvoir ajouter, modifier ou supprimer des ressources.

Vous pouvez consulter les ressources sans vous connecter sur la page principale. La connexion n'est nécessaire que pour modifier le contenu.
