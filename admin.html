Comment ça marche

L'ajout, la modification et la suppression des ressources se font désormais directement sur la page principale (bouton 🔒 Se connecter en haut à droite), avec un simple mot de passe que vous choisissez ci-dessous. Cette page sert uniquement, une seule fois, à créer ce mot de passe et à le relier à un vrai token GitHub — qui reste chiffré dans le code du site et n'est jamais transmis nulle part.

🛠️ Générer les identifiants éditeur

  1. Créez un fine-grained personal access token GitHub, limité à ce dépôt, permission Contents: Read and write uniquement (créer un token).
  2. Collez-le ci-dessous avec le mot de passe éditeur que vous voulez donner à vos collaborateurs (ex : APF2026!).
  3. Cliquez sur « Générer », copiez le bloc obtenu, et collez-le dans assets/config.js à la place de encryptedToken: null, puis commitez/pushez ce fichier.

Paramètres du dépôt

Valeurs déjà pré-remplies dans assets/config.js. À ne modifier que si vous changez de dépôt ou de branche.

Pour changer ces valeurs, éditez directement assets/config.js dans le code du site.
